How it works

Five steps, all offline

Read your sessions

Load local Claude Code and Codex logs for a chosen period.

Find the waste

Split tokens into prompts, tool outputs, file reads and repeats.

Apply each saver

Run each tool's compression on the recorded outputs.

Count and price

Count tokens with each model's tokenizer and apply its price.

Report and share

A terminal report plus a share card with numbers only.

Weekend scope

  • Claude Code and Codex session logs
  • 3–5 of the most-starred token savers
  • Token counts and cost per tool, per project
  • Share card that contains no code or prompts

Left out on purpose

  • A live proxy that changes sessions as they run
  • Re-running sessions against models (costly, and it changes the outcome)
  • Accounts, dashboards, telemetry

Risks

  • Offline replay can't show whether a saver changes how the agent behaves. The report must say so.
  • "Savers save less than claimed" is already public, so the personal view must lead. Claude Code's log format also changes between versions.
  • Anthropic keeps building savings in. Expect a spike, not a moat.
